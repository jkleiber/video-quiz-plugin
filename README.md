
# video-quiz-plugin

This is a plugin that takes the youtube video a user is watching as input, reads the transcript, and then creates quiz questions based on the content. 

The user has to answer the quiz questions at regular intervals throughout the video to prove understanding. 

This is a plugin aimed toward language learners.

The plugin works in the Chrome browser.

## Implementation

This idea is implemented as a Manifest V3 Chrome extension in `src/`. See
[docs/](docs/) for how it works, how to install it, and its known
limitations — start with [docs/USAGE.md](docs/USAGE.md) to try it out.
